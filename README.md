## 📖 Описание

Этот модпак создан для тех, кто любит исследовать, строить и сражаться.  
Здесь сочетаются технологии будущего и древняя магия. Ты начнешь с нуля в опасном мире, где каждый биом таит угрозу или сокровище.

**Основные фичи:**
- 🔧 Технические моды для автоматизации ресурсов.
- ✨ Магические моды для изучения древних знаний.
- 🌍 Улучшенная генерация мира (биомы, структуры).
- ⚔️ Новые мобы и боссы с уникальными механиками.

---

## 🚀 Как установить

1. Скачай **CurseForge** или **Prism Launcher**.
2. Импортируй архив `.zip` из этого репозитория.
3. Выдели **минимум 6 ГБ ОЗУ**.
4. Наслаждайся игрой!

## 🛠️ Для разработчиков

Этот репозиторий содержит:
- Папку `overrides` — конфиги, скрипты (KubeJS/CraftTweaker), ресурспаки.
- Папку `scripts` — пользовательские рецепты и правки баланса.
